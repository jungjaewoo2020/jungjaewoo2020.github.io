# Jaewoo Jung — unpublished website draft

This folder contains a new, unpublished design for Jaewoo Jung's academic homepage. It has not been connected to Google Sites or deployed to GitHub Pages. There is no deployment workflow in this folder.

Open `index.html` in a browser to preview the site locally. Keep all files together; the portrait, CV, thesis, styles, and script use relative paths. An internet connection loads Source Serif 4 and DM Sans from Google Fonts; system fonts are available as fallbacks.

The design preserves the biography, research interests, seven publications, and professional contact information from the previous homepage. The publication filters are optional enhancements: every paper is visible when JavaScript is unavailable.

Files:

- `index.html`: page content and links
- `styles.css`: responsive layout, typography, print layout, and accessibility styles
- `app.js`: publication filters
- `favicon.svg`: website icon
- `jaewoo-jung.jpg`: original portrait
- `cv-jaewoo-jung.pdf` and `phd-thesis.pdf`: linked documents
- `hankel-index-poster.pdf` and `regularity-poster.pdf`: preserved supporting documents

The canonical URL is prepared for the intended future address, `https://jungjaewoo2020.github.io/`. It does not publish or connect this draft. Publish only after the owner requests publication.

The biography retains the original phrase “certified master's degree in 2016.” Do not reinterpret this as a different qualification without the owner's clarification.
